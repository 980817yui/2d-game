# Ashenlight: Echoes Below

一個完全獨創的 Godot 4 2D 動作平台遊戲原型。遊戲名稱、角色、世界觀、敵人、場景、美術與玩法設計皆為本專案重新創作，不依賴或複製任何現有作品。

## 目前內容

- 深紫色像素風暮色場景與遺跡
- A/D 或方向鍵移動
- SPACE 跳躍
- J 或滑鼠左鍵近戰攻擊
- 兩個巡邏中的暗影敵人
- 擊敗敵人後取得靈魂火花
- 接觸敵人會受傷，生命歸零後回到起點
- E 與右側篝火互動，恢復生命；集齊兩枚火花後完成遠征
- 勝利面板與 ESC 重新開始流程
- 平台、重力、碰撞、平滑背景位移與 HUD

## 執行方式

使用 **Godot 4.x** 開啟本資料夾，按下 Play Project。主場景為 `main.tscn`。

## 操作

| 按鍵 | 功能 |
|---|---|
| A / D、方向鍵 | 左右移動 |
| SPACE | 跳躍 |
| J / 滑鼠左鍵 | 近戰攻擊 |
| E | 靠近篝火時互動 |

這是第一個可玩垂直切片，後續可擴展地圖串接、更多敵人、Boss、能力解鎖、對話與存檔系統。
